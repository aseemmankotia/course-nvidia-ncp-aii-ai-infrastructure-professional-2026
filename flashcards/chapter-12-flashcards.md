## Chapter 12: Full Exam Simulation and Time-Management Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | NCP-AII exam format: how many questions and how much time? | 70 questions, 120 minutes. Exam tip: raw average is ~103 sec/question — budget below that to build a review buffer. |
| 2 | Recommended per-question time budget on first pass, and why less than the raw average? | ~90 seconds/question. This is intentionally below the ~103-second raw average (120min÷70) to reserve ~10-15 minutes at the end for reviewing flagged questions. |
| 3 | Flag-and-skip rule of thumb: when should you flag a question instead of guessing and moving on? | Flag only if you can eliminate at least one wrong option but are unsure between the rest — always submit a best-guess answer first, never leave it blank, since unanswered = guaranteed zero. |
| 4 | InfiniBand vs RoCE — key exam differentiator? | InfiniBand: purpose-built RDMA fabric, lowest latency, requires dedicated switches, no Ethernet interop needed. RoCE: RDMA over standard/converged Ethernet, chosen when Ethernet interoperability or existing Ethernet infrastructure is required. |
| 5 | BCM (Base Command Manager) vs manual scripts for cluster management? | BCM = centralized provisioning, health monitoring, automated re-imaging at scale. Manual scripts = no centralized visibility, doesn't scale, no drift/health detection. Exam trap: 'add more engineers' to manual scripting is never the right answer. |
| 6 | Kubernetes vs Slurm for GPU workloads — when does each win? | Slurm: gang-scheduled, tightly-coupled HPC batch training jobs, exclusive node allocation, native HPC queueing. Kubernetes: microservices, inference serving, elastic container workloads. Exam trap: default K8s scheduler does NOT provide native gang scheduling. |
| 7 | Cross-domain scenario question pattern — how to solve efficiently? | Identify the ONE specific decision being asked (fabric choice? scheduler? storage tier?) and ignore extra domain context that isn't part of that decision. Don't assume the first-mentioned domain is the tested one. |
| 8 | Elimination strategy for exam distractors — first step? | Eliminate the 1-2 options that are obviously wrong (deprecated service, wrong scale, or violates a hard constraint) before comparing the remaining plausible options in detail. Saves time and reduces error. |
| 9 | Command to check InfiniBand link/port status on a node? | `ibstat` — shows port state (Active/Down), link speed, and rate. Exam tests recognizing 'Down' or mismatched rate as a fabric health trap. |
| 10 | Command to inspect a running Slurm job's details? | `scontrol show job <jobid>` — shows node allocation, state, and reason codes (e.g., PENDING reasons like Resources or Priority). |
| 11 | Final review pass strategy with limited time remaining — what NOT to do? | Do not re-read every answered question from scratch, and do not change confident answers based on a vague 'gut feeling' with no new information — both patterns statistically lower scores. |
| 12 | Terminology trap: 'manual' cluster management in a question stem usually signals what kind of correct answer? | It signals the correct answer is almost always the automated/centralized alternative (e.g., BCM) rather than 'more manual effort' or 'more staff' — a recurring cross-domain distractor pattern. |
