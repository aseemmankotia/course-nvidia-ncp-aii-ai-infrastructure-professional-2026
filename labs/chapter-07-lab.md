# Chapter 7 Lab: Provisioning with Base Command Manager (BCM)

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: review a BCM provisioning workflow diagram and identify the correct steps to provision a new set of compute nodes into an existing cluster

## Key takeaway

BCM standardizes both hardware provisioning and software-stack management across many nodes, making it the preferred approach over manual provisioning at cluster scale.
