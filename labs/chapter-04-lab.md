# Chapter 4 Lab: InfiniBand, RoCE, and BlueField DPU Deployment

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: given a described cluster requirement (workload type, budget, latency needs), select InfiniBand vs RoCE and justify the choice using published NVIDIA guidance

## Key takeaway

Fabric choice between InfiniBand and RoCE must match workload latency/bandwidth needs, and RoCE always requires lossless Ethernet configuration to function correctly.
