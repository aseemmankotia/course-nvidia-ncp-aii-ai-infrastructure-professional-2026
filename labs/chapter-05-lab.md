# Chapter 5 Lab: Cabling Standards, Transceivers, and Fabric Topology

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: review a described cluster scale requirement and select the correct topology (fat-tree vs rail-optimized) and transceiver type

## Key takeaway

Topology and transceiver selection must match both traffic pattern (rail-optimized for GPU east-west) and physical distance constraints (DAC vs AOC vs optical).
