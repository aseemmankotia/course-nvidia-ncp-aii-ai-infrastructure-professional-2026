# Chapter 3 Lab: Rack, Cable, and Configure Compute Servers

**Estimated time:** 15 minutes

## Exercise

Read-and-understand walkthrough: review a multi-node rack-and-cable diagram and select the correct cabling/configuration order for a described 8-node DGX cluster

## Key takeaway

Compute-layer bring-up requires correct rack airflow orientation and a strict driver-before-container-runtime install order across every node in the cluster.
