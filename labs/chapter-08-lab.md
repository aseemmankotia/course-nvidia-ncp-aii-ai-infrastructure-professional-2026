# Chapter 8 Lab: Kubernetes and the NVIDIA GPU Operator

**Estimated time:** 18 minutes

## Exercise

Read-and-understand walkthrough: review a GPU Operator Helm deployment manifest and Kubernetes pod spec, and identify the correct resource-allocation configuration for a shared multi-tenant cluster

## Key takeaway

The GPU Operator automates the full GPU software stack on Kubernetes nodes, and MIG is the correct mechanism for safely partitioning GPUs across multiple tenants.
